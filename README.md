# HR InterviewPlatform

Платформа технических собеседований для HR-отдела. Построена на .NET 10 + Go auth-service + React 19, оркестрируется через Docker Compose.

---

## Архитектура

| Сервис | Технология | Порт | Описание |
|--------|-----------|------|----------|
| Frontend | React 19 (CRA) + Nginx | 80 | SPA с интерфейсом управления |
| Backend | .NET 10 | 5126 | REST API с бизнес-логикой |
| Auth Service | Go 1.25 | 50051 | JWT-аутентификация, управление пользователями |
| Database | PostgreSQL 16 | 5432 | Общая БД для .NET и Go |

**57 REST-эндпоинтов**, **10 таблиц** в БД.

---

## Функционал

### Авторизация и роли

- JWT-аутентификация через Go auth-service
- Три роли: **Администратор**, **HR**, **Согласующий**
- Динамическая система прав с 30+ разрешениями (просмотр, создание, редактирование, архивация, удаление, восстановление)
- Каждый эндпоинт защищён атрибутами `[Authorize(Roles = "...")]`
- Удалённые пользователи не могут войти в систему

### Кандидаты

- Создание, редактирование, просмотр карточки кандидата
- Поля: ФИО, телефон (+7 формат), город, образование, опыт работы (число + года/лет), предыдущее место работы, навыки
- **Вычисляемый статус** на основе собеседований: Активен, Ожидает собеседования, Ожидает решения, Нанят, В кадровом резерве, Отклонён
- Архивация, soft delete с восстановлением
- Фильтры: по статусу, по опыту работы (диапазоны: без опыта, 1-2, 3-5, 5+), по алфавиту, по дате

### Собеседования

- Планирование собеседования (кандидат, вакансия, интервьюер, дата/время)
- Статусы: Запланировано → Проведено / Отменено
- **Четыре решения**: Нанять, Отклонить, Следующий этап, Кадровый резерв
- При решении "Нанять" / "Кадровый резерв" — автоматическая архивация остальных собеседований кандидата
- При отклонении всех собеседований — автоматическое отклонение кандидата
- **Перенос собеседования** — сброс статуса на "Запланировано", очистка оценок и комментариев, новый выбор даты/интервьюера/вакансии
- Обязательная оценка всех компетенций и комментарий перед завершением
- **Оценка компетенций** — звёздная матрица (1-5) для каждой компетенции из собеседования
- Архивация, soft delete с восстановлением

### Вакансии

- Создание, редактирование, просмотр с раскрывающимися требованиями
- Привязка необходимых компетенций
- Архивация, soft delete с восстановлением

### Компетенции

- Справочник навыков с категориями (Soft Skills, Backend, Frontend, Database, DevOps, Data)
- Описание, максимальный балл (1-5), статус активности
- Категории создаются прямо из формы
- Архивация, soft delete с восстановлением

### Пользователи и роли

- Управление пользователями (создание, редактирование, деактивация)
- Назначение ролей: Администратор, HR, Согласующий
- **Динамическое управление правами** — добавление/удаление ролей, переключение 30+ разрешений
- Soft delete с восстановлением

### Журнал аудита

- Автоматическое логирование всех действий (создание, редактирование, удаление, архивация, восстановление, решения, обновление матрицы)
- Фильтрация по области (Кандидаты, Собеседования, Вакансии, Компетенции, Пользователи)
- Фильтрация по типу действия, по дате, полнотекстовый поиск

### Архив и удалённое

- **Архив** — архивированные кандидаты, собеседования, компетенции с возможностью восстановления
- **Удалённое** — soft deleted элементы всех типов (кандидаты, собеседования, вакансии, компетенции, пользователи) с фильтрацией по категории и восстановлением

### PDF-отчёты

- Карточка кандидата
- Протокол собеседования
- Письмо о решении (оффер / отказ)

### Поиск и фильтры

- Универсальный компонент `SearchFilter` с иконкой-фильтром
- Мульти-выбор для статусов, категорий, ролей, областей
- Диапазоны для числовых полей (опыт работы)
- Сортировка: по дате (новые/старые), по алфавиту
- Фильтры по дате (от/до) с валидацией диапазона

```

├── src/                                # .NET Backend
│   ├── InterviewPlatform.API/          # Контроллеры, middleware, Program.cs

│   ├── cmd/server/main.go             # HTTP-хендлеры
│   ├── internal/service/              # Бизнес-логика (login, register, JWT)
│   ├── internal/repository/           # Работа с PostgreSQL
│   └── internal/token/                # Генерация JWT
├── ui/                                 # React Frontend
│   └── src/
│       ├── App.js                     # Основной компонент (~2600 строк)
│       ├── api.js                     # API-клиент с JWT
│       ├── components/                # SearchFilter, модалки
│       ├── constants/                 # Права, роли, цвета
│       ├── pages/                     # ArchivePage, DeletedPage
│       └── utils/                     # Форматирование, PDF, цвета
├── docker-compose.yml
└── Dockerfile (frontend)
```
